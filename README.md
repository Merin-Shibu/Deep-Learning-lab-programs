# Deep Learning Lab Programs

This repository contains the implementation of eight Deep Learning laboratory experiments as part of the VTU 7th Semester curriculum (CSE AIML).

## Experiments

1. Word Embedding Generation using Word2Vec
2. Deep Neural Network Classification
3. CNN Image Classification
4. Autoencoder for Image Compression
5. Text Document Classification
6. Time Series Forecasting using LSTM
7. Transfer Learning using MobileNetV2
8. Sentiment Analysis

## Technologies Used

- Python
- NumPy
- Pandas
- TensorFlow / Keras
- Gensim
- Scikit-learn
- Matplotlib

## Tools

- Visual Studio Code
- Jupyter Notebook
- Git and GitHub

## Purpose

To understand and implement different deep learning techniques through practical laboratory experiments.
